# 배포 범위와 검증 기록

2026-10-24 저장본 기준입니다. 원본 Bridge 프로젝트의 Content·Config·uproject를 별도 작업 사본에 일반 파일 복사한 뒤, 사본에서 Unreal의 정식 액터 삭제·저장 절차로 환경 범위를 줄였습니다. 최종 배포에는 새 의존성 집합만 복사했으며 원본 `.git`이나 LFS 객체·기존 커밋 이력을 가져오지 않았습니다.

처음 정리한 환경 액터 8,169개에 이어 생성 HLOD 121개와 모든 검사 프레임의 보수적 카메라 범위 밖 지하 BP 4개를 추가로 제외했습니다. 이 숫자는 서로 다른 정리 단계이며 전체 원본 파일 수에서 단순히 빼는 계산식이 아닙니다. 최종 Main의 fresh descriptor와 실제 자동 로드 액터는 모두 912개입니다. 살아 있는 외부 액터·오브젝트 패키지와 시퀀스·재질·FX·캐릭터의 hard/soft 의존성 경로는 유지했습니다.

## 근거 파일

- `PAYLOAD_MANIFEST.csv`: 최종 export가 기록한 1,804개 파일의 경로·크기·SHA-256. Config와 descriptor의 원래 바이트까지 보존합니다.
- `DEPENDENCIES.json`: 최종 fresh UE 검사에서 회수한 `/Game` 패키지 그래프와 엔진 측 의존성 mount.
- `VALIDATION.json`: export·fresh 엔진 검사·원본 보존·Git 재현 검사의 요약 및 근거 파일명과 해시.

원본 보존 검사는 저장된 원본 파일 12,103개의 크기와 nanosecond mtime를 작업 전 목록과 비교했고 변경·누락·추가 0개였습니다. 원본 전체를 다시 해시한 검사는 아니며 에디터의 미저장 메모리까지 보존했다고 주장하지 않습니다.

## 확인된 항목과 한계

최종 export 경로의 프로젝트를 새 NullRHI 프로세스로 직접 열었습니다. 누락 패키지와 제거된 패키지 참조는 0개, 223개 프레임의 카메라 값과 시퀀스 키는 기준과 일치했습니다. Actor2 부모와 새 SHOOT2 FX 바인딩·표시 상태·Niagara 참조는 데이터 수준에서 확인했습니다.

최종 slim의 GPU 픽셀·조명·실시간 Niagara 외관과 전체 시퀀스 재생은 별도 시각 확인이 필요합니다. NullRHI에서는 렌더 결과를 판단할 수 없습니다. 평가 중 생긴 SHOOT2 외부 액터의 메모리 dirty 상태는 저장하지 않았습니다.

Git 검증은 이 배포본만 담은 새 이력, 자산의 LFS 포인터와 manifest SHA 일치, 생성 캐시·비밀정보 제외, 로컬 clean clone에서의 실제 파일 복원을 대상으로 합니다. 로컬 clone 성공은 GitHub 원격 업로드 성공과 별개입니다. 원격 저장소와 계정의 무료 LFS 잔여량·과금 차단은 업로드 단계에서 확인합니다.
